Dammsäkerhetsövervakning och tillståndsbedömning#

Data Lab – första version

Syftet med fallstudien är att visa hur dammsäkerhetsövervakning, mätdata, verifieringskontroller och tillståndsbedömning kan struktureras och beskrivas på svenska. Fallstudien bygger på syntetiska data, men arbetsflödet och de tekniska begreppen anknyter till erfarenhet av verklig dammövervakning.

Detta fallstudieprojekt visar hur övervakningsdata, fysikaliska verifieringar och inspektionsobservationer kan kombineras för att stödja en strukturerad bedömning av en damms tekniska tillstånd.

Projektet använder syntetiska data och är ett pedagogiskt portfolioexempel, inte en verklig dammsäkerhetsutredning.

Arbetsflöde#

mätdata → kvalitetskontroll → förväntat beteende → avvikelseanalys → inspektionsfynd → tillståndsbedömning → rekommenderad uppföljning

1. Syntetisk damm och instrumentering#

Vi skapar två år med dagliga data för:

  • magasinsnivå

  • nedströms vattennivå

  • temperatur

  • tre piezometrar

  • läckageflöde

  • krönsättning

  • horisontell förskjutning

Kontrollerade avvikelser läggs in för att göra analysen mer realistisk.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(42)
datum = pd.date_range("2024-01-01", periods=730, freq="D")
t = np.arange(len(datum))

magasin = 102 + 4.5*np.sin(2*np.pi*t/365) + 0.8*np.sin(2*np.pi*t/30) + rng.normal(0,0.15,len(t))
nedstrom = 74 + 0.7*np.sin(2*np.pi*t/365 + 0.8) + rng.normal(0,0.08,len(t))
temperatur = 7 + 12*np.sin(2*np.pi*(t-170)/365) + rng.normal(0,1.2,len(t))

p1 = 120 + 4.3*(magasin-100) + 0.12*temperatur + rng.normal(0,1.5,len(t))
p2 = 110 + 3.8*(magasin-100) + 0.10*temperatur + rng.normal(0,1.4,len(t))
p3 = 100 + 3.2*(magasin-100) + 0.09*temperatur + rng.normal(0,1.3,len(t))

lackage = 18 + 1.6*(magasin-100) - 0.08*temperatur + rng.normal(0,0.5,len(t))
sattning = 0.004*t + 0.5*np.sin(2*np.pi*t/365) + rng.normal(0,0.08,len(t))
forskjutning = 2*np.sin(2*np.pi*t/365) + 0.03*(magasin-100) + rng.normal(0,0.12,len(t))

# Kontrollerade avvikelser
lackage[430:] += np.linspace(0,6,len(t)-430)
p3[500:] += np.linspace(0,18,len(t)-500)
sattning[560:] += 0.012*np.arange(len(t)-560)

df = pd.DataFrame({
    "datum": datum,
    "magasinsnivå_m": magasin,
    "nedströmsnivå_m": nedstrom,
    "temperatur_C": temperatur,
    "portryck_P1_kPa": p1,
    "portryck_P2_kPa": p2,
    "portryck_P3_kPa": p3,
    "läckage_l_s": lackage,
    "krönsättning_mm": sattning,
    "horisontell_förskjutning_mm": forskjutning
})
display(df.head())

3. Datakvalitet och verifieringskontroller#

Innan en avvikelse tolkas som ett dammsäkerhetsproblem bör mätningen kontrolleras.

Exempel:

  • saknade värden

  • abrupta hopp

  • orimliga negativa värden

  • värden utanför historiskt intervall

  • inkonsistens mellan närliggande instrument

4. Förväntat läckagebeteende#

Vi bygger en enkel modell:

\[ q = f(H,T) \]

där (q) är läckageflöde, (H) magasinsnivå och (T) temperatur.

Den första delen av serien används som referensperiod.

Show code cell source

Hide code cell source

 
import plotly.graph_objects as go

train_end = 400

X_train = df.loc[
    :train_end-1,
    ["magasinsnivå_m", "temperatur_C"]
]

y_train = df.loc[:train_end-1, "läckage_l_s"]

modell_lackage = LinearRegression().fit(
    X_train,
    y_train
)

df["läckage_förväntat_l_s"] = modell_lackage.predict(
    df[["magasinsnivå_m", "temperatur_C"]]
)

df["läckage_restfel_l_s"] = (
    df["läckage_l_s"]
    - df["läckage_förväntat_l_s"]
)

sigma_q = df.loc[
    :train_end-1,
    "läckage_restfel_l_s"
].std()

grans_q = 3 * sigma_q

fig = go.Figure()

fig.add_trace(
    go.Scatter(
        x=df["datum"],
        y=df["läckage_restfel_l_s"],
        mode="lines",
        name="Restfel"
    )
)

fig.add_hline(
    y=grans_q,
    line_dash="dash",
    annotation_text="+3σ",
    annotation_position="top left"
)

fig.add_hline(
    y=-grans_q,
    line_dash="dash",
    annotation_text="-3σ",
    annotation_position="bottom left"
)

fig.update_layout(
    title="Avvikelse från förväntat läckage",
    width=width, height=height,
    xaxis_title="Datum",
    yaxis_title="Restfel [l/s]",
    template="plotly_white",
    hovermode="x unified"
)

display(fig)

Tolkning#

Ett växande positivt restfel betyder att uppmätt läckage är högre än modellen förväntar sig utifrån nivå och temperatur.

Det betyder inte automatiskt försämrad dammsäkerhet. Det bör följas upp genom exempelvis instrumentkontroll, jämförelse med närliggande mätpunkter, kontroll av dränage och riktad inspektion.

Ingenjörsmässig bedömning#

Om P3 avviker tydligt medan P1, P2 och läckaget är stabila kan orsaken vara:

  • instrumentdrift

  • lokal effekt

  • kabel-/loggerproblem

  • behov av verifieringsmätning

Om flera oberoende signaler förändras samtidigt blir en verklig förändring i dammens tillstånd mer sannolik.

8. Enkel integrerad tillståndsbedömning#

Show code cell source

Hide code cell source

 
senaste = df.iloc[-1]
status = []

if senaste["läckage_restfel_l_s"] > grans_q:
    status.append(("Läckage", "Uppföljning krävs", "Högre än förväntat utifrån nivå och temperatur"))
else:
    status.append(("Läckage", "Normal", "Inom förväntat intervall"))

if abs(senaste["P3_restfel_kPa"]) > grans_p3:
    status.append(("Piezometer P3", "Uppföljning krävs", "Avviker från P1 och P2"))
else:
    status.append(("Piezometer P3", "Normal", "Följer närliggande instrument"))

recent = df["krönsättning_mm"].tail(60)
previous = df["krönsättning_mm"].iloc[-120:-60]
if recent.mean() - previous.mean() > 0.8:
    status.append(("Krönsättning", "Uppföljning krävs", "Ökad sättningstakt"))
else:
    status.append(("Krönsättning", "Normal", "Ingen tydlig accelererande trend"))

status_df = pd.DataFrame(status, columns=["parameter","status","motivering"])
display(status_df)

9. Exempel på dammsäkerhetssammanfattning#

Övergripande bedömning: Uppföljning rekommenderas.

Viktigaste observationer:

  • läckageflödet ligger över förväntad nivå

  • P3 avviker relativt P1 och P2

  • krönsättningen visar tecken på ökad förändringstakt

  • ett fuktigt område har observerats på nedströmsslänten

Rekommenderade nästa steg:

  1. kontrollera dränage och läckagemätning

  2. verifieringsmät P3

  3. jämför sättningsutvecklingen mot historik

  4. genomför riktad inspektion

  5. fortsätt tätare uppföljning tills avvikelserna är förklarade

En verklig dammsäkerhetsbedömning kräver anläggningsspecifik dokumentation, gränsvärden, historik och gällande rutiner.
