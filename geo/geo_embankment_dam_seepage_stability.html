This is a conceptual portfolio model, not a design calculation. The seepage solution uses a simplified Dupuit-type approximation, and the stability section uses an infinite-slope screening model.

Simplified steady seepage#

For a first transparent model:

\[ q = \frac{k(h_1^2-h_2^2)}{2L} \]

and

\[ h(x)=\sqrt{h_1^2-\frac{h_1^2-h_2^2}{L}x} \]

This is a simplified analytical approximation, not a full 2D FEM seepage solution.

Hide code cell source

 
x_start = x_up_crest - upstream_ratio * (H - reservoir_level)
x_end = x_down_toe
L = x_end - x_start
h1, h2 = reservoir_level, 0.0

q_per_m = k * (h1**2 - h2**2) / (2 * L)

x = np.linspace(x_start, x_end, 500)
xi = x - x_start
h = np.sqrt(
    np.maximum(
        h1**2 - (h1**2 - h2**2) * xi / L,

Pore-pressure field#

Below the phreatic surface:

\[ u = \gamma_w(h-y) \]

Above the phreatic surface, this simple model sets (u=0).

Hide code cell source

 
import numpy as np
import plotly.graph_objects as go

gamma_w = 9.81  # kN/m³ -> kPa when multiplied by metres

X, Y = np.meshgrid(
    np.linspace(x_start, x_end, 240),
    np.linspace(0, H, 150)
)

def dam_surface(xv):
    xv = np.asarray(xv)
    ys = np.zeros_like(xv, dtype=float)

    m1 = (xv >= x_up_toe) & (xv < x_up_crest)
    ys[m1] = xv[m1] / upstream_ratio

    m2 = (xv >= x_up_crest) & (xv <= x_down_crest)
    ys[m2] = H

    m3 = (xv > x_down_crest) & (xv <= x_down_toe)
    ys[m3] = H - (xv[m3] - x_down_crest) / downstream_ratio

    return np.maximum(ys, 0)

dam_top = dam_surface(X)
xi_grid = X - x_start
Hph = np.sqrt(np.maximum(h1**2 - (h1**2 - h2**2) * xi_grid / L, 0))

inside = (Y <= dam_top)

U = gamma_w * np.maximum(Hph - Y, 0)
U[~inside] = np.nan

Synthetic piezometers: model vs monitoring#

This section demonstrates the workflow:

model prediction → field measurement → residual → engineering interpretation

In a real dam-safety project, the observed values would come from field piezometers.

import numpy as np
import pandas as pd
import plotly.graph_objects as go

rng = np.random.default_rng(42)

piezometers = pd.DataFrame({
    "Piezometer": ["P1", "P2", "P3", "P4", "P5"],
    "x_m": [
        x_start + 25,
        x_start + 50,
        x_start + 75,
        x_start + 100,
        x_start + 125
    ],
    "y_m": [5, 8, 6, 4, 2]
})

def phreatic_elevation(xp):
    xi = xp - x_start

    return np.sqrt(
        np.maximum(
            h1**2 - (h1**2 - h2**2) * xi / L,
            0
        )
    )

piezometers["h_model_m"] = phreatic_elevation(
    piezometers["x_m"].to_numpy()
)

piezometers["u_model_kPa"] = gamma_w * np.maximum(
    piezometers["h_model_m"] - piezometers["y_m"],
    0
)

piezometers["u_observed_kPa"] = np.maximum(
    piezometers["u_model_kPa"]
    + rng.normal(0, 5, len(piezometers)),
    0
)

piezometers["residual_kPa"] = (
    piezometers["u_observed_kPa"]
    - piezometers["u_model_kPa"]
)

display(piezometers.round(2))

Simplified slope-stability screening#

We use an infinite-slope sensitivity model:

[ FS= \frac{c’}{\gamma z\sin\beta\cos\beta} +(1-r_u)\frac{\tan\phi’}{\tan\beta} ]

This is not a substitute for a full Bishop / Morgenstern–Price / SLOPE/W analysis.

Show code cell source

Hide code cell source

 
gamma_soil = 20.0
c_eff = 5.0
phi_eff_deg = 32.0
z = 8.0

beta = np.arctan(1/downstream_ratio)
phi_eff = np.deg2rad(phi_eff_deg)

def infinite_slope_fs(ru):
    return (
        c_eff/(gamma_soil*z*np.sin(beta)*np.cos(beta))
        + (1-ru)*np.tan(phi_eff)/np.tan(beta)
    )

ru_values = np.linspace(0, 0.6, 100)
fs_values = np.array([infinite_slope_fs(ru) for ru in ru_values])

Scenario study#

Compare normal conditions, higher reservoir level, and higher permeability.

Show code cell source

Hide code cell source

 
scenarios = pd.DataFrame([
    {"Scenario":"Normal", "reservoir_level_m":24.0, "k_m_s":1e-6},
    {"Scenario":"High reservoir", "reservoir_level_m":28.0, "k_m_s":1e-6},
    {"Scenario":"Higher permeability", "reservoir_level_m":24.0, "k_m_s":5e-6},
    {"Scenario":"High reservoir + higher k", "reservoir_level_m":28.0, "k_m_s":5e-6},
])

def seepage_q(level, kval):
    xstart = x_up_crest - upstream_ratio*(H-level)
    length = x_down_toe - xstart
    return kval*level**2/(2*length)

scenarios["q_m2_s"] = [seepage_q(r.reservoir_level_m, r.k_m_s) for r in scenarios.itertuples()]
scenarios["relative_to_normal"] = scenarios["q_m2_s"]/scenarios.loc[0,"q_m2_s"]
display(scenarios)
